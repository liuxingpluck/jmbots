# 系统提示词

仓库这里是**出厂默认**：程序启动时复制到运行时目录的 `prompts/`（已有的不覆盖）。**要改就改运行时目录那份。**

## 规矩

- 系统提示词按文件名取，固定拼法是 `00_base_dsh.md` + 对应语言的那一篇（见 `src/resources/Resources.ts` 的 `prompt`）。不是“目录里的 .md 全拼上”。
- **`00_base_dsh.md` 永远排第一段，一个字都不改**。它是 DSH 的系统提示词原文，所有语言共用。提示词缓存是按前缀逐字节比的，第一段不变，缓存才命中。用户 2026-11-04：“确保第一段永远是原声的、没有任何变化的哦，这样的话呢我们可以命中缓存的。”
- 第二段按机器人的 `language` 选 `zh/` 或 `en/`。

## 现有

| 文件 | 作用 |
| --- | --- |
| `00_base_dsh.md` | DSH 的系统提示词原文，原样照抄。 |
| `zh/10_机器人.md`、`en/10_bot.md` | 机器人在会话里的系统提示词：收到的消息长什么样、怎么回复、工作区和会话、记忆和技能、13 个工具。 |
| `zh/20_分派.md`、`en/20_dispatch.md` | 分派的常规模型档：定打断谁、放哪、新开还是追加、用什么模型，只回 JSON。 |
| `zh/30_审核.md`、`en/30_review.md` | exec 审核的小循环：判断命令能不能直接执行，写清做什么、风险、建议，只回 JSON。 |

技能清单（运行时 `skills/` 下每个技能一行）由程序接在机器人提示词后面，不在这里。各篇的来由见 `docs/10_以机器人为核心的新框架_20261105.md` 第 7 节。

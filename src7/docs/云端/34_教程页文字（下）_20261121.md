### 2.2 四条检查

挂在 `LineChecker` 逐份查 Markdown 的循环里（`Check_Lines.ts:589-594`），文件是 `src7/plugins/<名字>/说明.md` 时多调一个方法。示意（待核）：

```ts
/** 说明.md 必须有的二级标题：CLAUDE.md「每个插件都要有版本号和说明」列的那几样，没有就写“无”。 */
const DOC_SECTIONS = ['依赖', '听的事件', '发的事件', '对外函数', '内部函数', '数据', '配置'];

/** 插件源码里收发事件的写法：on、emit、serial、requestEvent、onRequestEvent 的第一个字符串参数。 */
const EVENT_USE = /\b(?:on|emit|serial|requestEvent|onRequestEvent)\((?:this\.)?(?:ctx, )?'([a-z][a-z0-9-]*\/[a-z0-9-]+)'/gu;

  /**
   * 查一份插件说明的形状：标准标题齐不齐、事件表漏没漏、index.ts 首句能不能当步骤标题。
   * @param rel 说明.md 相对代码库根目录的路径，形如 src7/plugins/<名字>/说明.md。
   */
  private checkPluginDoc(rel: string): void {
    //M 按二级标题切段。
    const text = fs.readFileSync(path.join(this.root, rel), 'utf8');
    const sections = getSections(text);

    //M 缺的标准标题各报一条：教程页认不出，内容跑进「补充」，对应标签变灰。
    for (const title of DOC_SECTIONS) {
      if (sections.has(title)) continue;

      this.report('error', rel, rel + ':1', '缺 `## ' + title + '`（没有就写“无”）');
    }

    //M 插件源码里收发、两张事件表都没写的事件，各报一条。
    const folder = path.dirname(rel);
    const used = this.getUsedEvents(folder);
    const listened = sections.get('听的事件') ?? '';
    const emitted = sections.get('发的事件') ?? '';
    for (const [event, site] of used) {
      if (listened.includes(event)) continue;
      if (emitted.includes(event)) continue;

      this.report('error', rel, site, '用了 `' + event + '`，事件表没写');
    }

    //M index.ts 文件头第一句是启动画布的步骤标题：超过 50 字会被截断，以冒号结尾只剩半句。
    const entry = folder + '/index.ts';
    const head = this.getHeadSentence(entry);
    if (head.length > 50) {
      this.report('error', rel, entry + ':1', '文件头第一句 ' + String(head.length) + ' 字，步骤标题会截断');
    }
    if (head.endsWith('：')) {
      this.report('error', rel, entry + ':1', '文件头第一句以冒号结尾，步骤标题只剩半句');
    }
  }
```

另外三个小函数：`getSections`（按 `## ` 切段，跳过代码块，约 15 行）、`getUsedEvents`（扫插件文件夹里不是测试的 .ts，记每个事件第一次出现的“文件:行号”，约 15 行）、`getHeadSentence`（取文件头第一行有字的注释、截到第一个句号或分号，和 `getFirstSentence` 同一个取法，约 10 行）。`requestEvent`、`onRequestEvent` 只取第一个参数，请求和回执一对只算一次，不用另外配对。“找不到 X 是哪个文件”在当前文档里改报 `error`，归档文档照旧报提示（`isArchive` 已有）。

## 1. 查不过抛什么：Checks 抛普通 Error，于是每个插件自己写一套

### 1.1 现状

`utils/Checks.ts` 的通用校验都抛普通 Error：`checkRecord`（`:301`）、`checkArray`（`:314`）、`checkNonEmptyText`（`:327`）、`checkNumber`（`:373`）、`checkAllowedValue`（`:468`）。只有 `checkCount`（`:490`）想到了 HTTP，用的是 `Object.assign(new Error(…), { statusCode: 400 })`（`:497`），同样的写法在这个文件里还有 5 处（`:519`、`:527`、`:558`、`:579`、`:587`）。

HTTP 出错处理（`http/index.ts:140-158`）只认两样：带 `statusCode` 的，和 `Failure`，别的一律回 500。所以 HTTP 插件没法直接调 `checkRecord`，一调，用户填错了就回 500。结果是：

| 同一件事 | 现在有几份 | 在哪 |
|---|---|---|
| 请求体要是 JSON 对象 | 4 | `knowledge/Routes.ts:105` 的 `readBodyRecord`；`frpc/index.ts:140` 的 `readBodyObject`（和上一个逐字一样）；`web-api/index.ts:383` 内联；`work-decision/Store.ts:15` 的 `readObject` |
| 网址里的非负整数 | 4，加上现成的 `checkCount` | `knowledge/Routes.ts:180` 的 `parseOptionalInt`；`frpc/index.ts:153` 的 `parseLogLinesCount`；`relay/Routes.ts:57` 的 `whole`（用 `Number()`，收 `1e3`、`2.0`，比别的松）；`work-decision/Routes.ts:366-370` 内联 |
| 端口 1..65535 | 1，加上现成的 `checkNumber` | `frpc/Toml.ts:381` 的 `checkPort`：等于 `checkNumber(v, label, { integer: true, min: 1, max: 65535 })`，只是抛的是 Failure |
| 抓到错翻成 400 | 2 段 | `relay/TaskRoutes.ts:127-135`、`:184-190`：`relay/Checks.ts` 抛普通 Error，路由只好包一层 |
| 23 号第 2 条那几处 | 9 | `Checks.ts` 的 6 处 `statusCode: 400`；`journal/index.ts:415`；`exec/Runs.ts:74` 的 `BadInput`（只为了在 `:525` 认出来回 400） |

`Failure(400` 在 `plugins/` 下出现了 146 次（web-api 41、knowledge 32、settings 22、frpc 21……），大部分是各插件自己的 `readXxx`。

### 1.2 根因

CLAUDE.md 规定了**在哪里**校验（入口一次），检查函数**放哪里**（`utils/Checks.ts`），没规定**查不过抛什么**。Checks 最早是给启动时读配置写的，抛普通 Error 足够了，Main 打印出来就退出。后来 HTTP 插件越来越多，入参校验也该用它，可它抛的错 HTTP 不认。于是每个插件各想办法：有的给普通 Error 挂上 statusCode，有的抛 Failure，有的包 try/catch，有的自己写一个 `BadInput` 类。

### 1.3 三种改法比一比

| 改法 | 做法 | 代价 |
|---|---|---|
| **A（推荐）** | Checks 里的 `checkXxx` 一律抛 `Failure(400, 原来那句话)` | 改一个文件。启动时读配置也抛 Failure，Failure 是 Error 的子类，打印出来一样 |
| B | Checks 里另加一套给 HTTP 用的（`checkBody`、`checkQueryInt`……） | 同一件事又多出两份，正是本篇要消掉的那种重复 |
| C | 加一个 `asBadRequest(() => checks.checkXxx(…))` 包装 | 每个调用处多套一层，读起来绕；忘了套就是 500 |

/** 标签名去掉两头空白和开头的 #。建标签、按标签筛、按名字找标签都用它。 */
function cleanTag(raw: string): string {
  const trimmed = raw.trim();
  const noHash = trimmed.replace(/^#+/u, '');
  return noHash.trim();
}

/** 名称、标题：去掉两头空白后不能是空的。 */

}

## 4. 本地时间写成字：5 份

| 在哪 | 写成什么 | utils 里现成的 |
|---|---|---|

```ts
export function generateAtomId(prefix = '', now = new Date()): string {
  //M 时刻取 utils 的时刻号前 17 位（年月日时分秒毫秒，本地时间），后面接 3 个小写字母。
  const stamp = namesModule.createTimestampId(now).slice(0, 17);
  return `${prefix}${stamp}${randomLetters3()}`;
}

export function formatDateFolder(timestampMs: number): string {
  //M 日期目录就是时刻号的前 8 位。
  const at = new Date(timestampMs);
  return namesModule.createTimestampId(at).slice(0, 8);
}
```

风险低：输出逐字不变，库里已有的 ID 也不受影响。

## 四、怎么扫出来的（复查用）

- **浅克隆**：`git rev-parse --is-shallow-repository` 是 `true` 时，先 `git fetch --unshallow origin main`，不然 `git log -S` 找不到 11-19 以前的提交。
- **兼容代码的量**：`git grep -nE "兼容|旧的|旧版|旧任务|旧会话|旧配置|旧测试|legacy|Legacy" <提交> -- 'src7/*.ts' ':!*.test.ts' | wc -l`，依次看 `4db67b6`、`b5a70a3`。
- **迁移和退场**：`git grep -n "ALTER TABLE" -- 'src7/*.ts' ':!*.test.ts'`；`git grep -n "\.migrate(" …`；`git grep -n "退场" -- 'src7/*.ts'`；规矩的出生用 `git log -S'迁移有账本' -- CLAUDE.md`。
- **RequestEvent 的过渡写法**：对 `onFallback`、`keepAlive`、`replySynchronously`、`isUnsure`、`RequestFallback` 逐个 `git grep -n <名字> -- 'src7/*.ts' ':!*.test.ts' ':!src7/utils/RequestEvent.ts'`；历史用 `git log -S'onFallback' -- src7/utils/RequestEvent.ts`，再在 `1bc784c`、`01bdeed`、`638c677` 上数生产调用数。
- **被白名单挡住的已跟踪文件**：`git ls-files -ci --exclude-standard`；新文件会不会被挡：`git check-ignore -v --no-index <路径>`。
- **孤儿翻译键**：读 `web/src/locales/en.json` 的键，在 `web/src`、`src7` 的非测试 `.ts`、`.tsx` 里逐个找原文。
- **组块阅读的行号引用**：`grep -cE '[A-Za-z]+\.(ts|tsx):[0-9]+' <文件>`，逐块数。

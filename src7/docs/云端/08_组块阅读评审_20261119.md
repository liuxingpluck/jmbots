## 第三块 插件之间一问一答

### 3.1 【结论 1】`handled` 的理由讲错了

**事实**：

- Cordis 4.0.0-rc.12 的 `serial`（`node_modules/cordis/lib/index.js:754–760`）：

  ```js
  async serial(...args) {
    const [thisArg, callbacks] = this._resolve("serial", args);
    for (const callback of callbacks) {
      const result = await Reflect.apply(callback, thisArg, args);
      if (isBailed(result)) return result;
    }
  }
  ```

  每个监听函数返回的 Promise 都会被 `await` 掉，才问下一个。`onRequestEvent` 的监听函数是 `async`，里面 `await handler(request)`（`RequestEvent.ts:166–173`），所以办事方办完、回执也发了，`serial` 才往下走。

- **实测**（bun，脚本放在临时目录，没提交）。办事方 A 写成先 `await Bun.sleep(50)` 再标 `handled`、再发回执；后面再挂一个监听 B。结果：
  - `requestEvent` 拿到的是 A 的真回执 `late-ok`，不是 `unhandled`；
  - B 是在 A 办完之后才被问到的，问到时看见 `handled=true`。

**所以**：“必须在第一个 `await` 之前标，不然误判没人接”这句不成立。早标只在一种写法下要紧：监听函数把活扔到后台、自己不等（`void this.x()`）就返回。另外，“慢的办事方会把排在它后面的监听者都挡住”这一点，文中完全没提，读者应该知道。

**改前、改后**：

- 概念三“一句话”
  - 改前：“办事的插件一看是自己的活，就**立刻同步**把 `request.handled = true`（举手，必须在第一个 `await` 之前）；全部问完还没人举手，说明没人管，提问方立刻拿到退回，不用傻等超时。”
  - 改后：

    > 请求事件是用 `ctx.serial` 挨个问的，而 `serial` 会**等每个监听函数跑完**（连它里面的 `await`），才问下一个。所以接活的插件是当场办完、把回执发出去，才轮到下一个人。全部问完，提问方再看 `handled`：没人标，说明没人管，立刻退回，不用傻等超时。不是自己的活就别标（`filter` 返回 false），留给后面的人。

  - 再加一句：

    > `onRequestEvent` 在第一个 `await` 之前就标好 `handled`，这是个保险：万一有人把活扔到后台不等，提问方也不会误判。

- 概念三的类比
  - 改前：“会议上问‘谁负责这件事？’——负责的人马上举手……”
  - 改后：

    > 还是第一块的传阅单：一个人一个人地传，接活的人当场办完、在单子上签“已接”，再往下传；传完一圈没人签，原样退回。

- 自测 2
  - 改前，问题：“办事的插件为什么要在第一个 `await` 之前就设 `handled = true`？……”；答案：“……如果办事方等 `await` 之后才设，提问方会误判‘没人接’。”
  - 改后，问题：

    > 办事的插件什么时候该标 `handled`？它办得很慢时，排在它后面的监听者和提问方各会怎样？

  - 改后，答案：

    > 是自己的活就标，不是就不标（`filter`）。`serial` 会等它办完才问下一个，所以后面的人都得等。提问方的超时照样计时，到点先拿退回；但办事方不会因此被叫停，还会接着办完（见概念四）。

### 5.5 待核：超时当拒绝以后，命令还可能跑

推演链（代码都核过；会不会真超时，取决于模型快慢，没真跑）：

1. exec 等 `approval/result` 最多 65 秒（`exec/Runs.ts:66`），超时退回“审核未就绪或超时，没有审核就不跑命令”（`Runs.ts:108–114`）。

3. 用户点同意 → `approval/decided` → exec 的 `onDecided`（`exec/index.ts:307`）真跑命令，再往会话里补一句“用户同意了，命令已经执行”。

结果：模型先被告知“没跑”，过一会儿命令又跑了。用户是同意了的，不算越权，但第五块“超时……一律当拒绝”会让人以为命令一定不跑。

建议：

- 文档先补半句：“退回只是 exec 不等了，approval 可能还会弹卡片”；
- 要不要在代码里处理，交 07 复查或本地真跑后定。

## 骨架四模块

| 模块 | 当前职责 | 代码入口 |
|---|---|---|
| Main | 建立资源/会话/工具并挂载插件，发 ready，恢复会话 | `src7/Main.ts:1` |
| Resources | 读配置、数据库和供应商模型资源 | `src7/Resources.ts:1` |

## 每个插件的用途

- **approval**：命令/工具/用户待确认审核
- **assist**：辅助能力工具与提示
- **base-bridge**：基地HTTP转发、通知与更新提醒
- **bots**：机器人、前后台分派、提示词与渠道工具
- **channels**：渠道协议（消息、回复、回执、撤回的事件和类型），不挂服务，渠道和 bots 直接 import
- **cli**：命令行渠道
- **context-fit**：上下文压缩与摘要
- **decision**：多模型/分类器决策
- **work-decision**：主人按工作区决定待定事项，选择送回提问会话或外部助手
- **desktop**：Windows窗口定位、截图与滚动
- **exec**：命令执行与运行窗口
- **fake-model**：离线假模型
- **feishu**：飞书渠道、卡片与文件
- **file-tools**：文件读写与工作区工具，含技能清单与 skill 工具（原 skills）
- **http**：统一Fastify、健康与鉴权，含网页托管与文件接口（原 web）
- **image-gen**：生图工具
- **journal**：流水与会话文件镜像
- **memory**：记忆检索、历史索引与关系图
- **model-catalog**：模型目录、可用性与回退
- **programs**：托管外部程序、转发其界面，并做资源守卫
- **progress**：进度计时、收尾、复盘与转交
- **relay**：外部助手/任务通道与回信
- **screen**：录屏讲解，收基地提交的已过隐私检查的点击，用可读图模型生成一两句中文说明
- **settings**：配置、机器人管理与重连
- **tutorial**：启动/运行快照、流程轨迹与源码教程
- **voice**：语音，聊天输入区开麦、字幕和转写状态
- **web-api**：网页消息/历史/追溯HTTP渠道
- **web-search**：联网搜索工具
- **wechat**：微信客服渠道与发送确认
- **workspaces**：工作区权限、登记与解析

## 如何使用与边界

- 生成表里“听的事件”包括 onRequestEvent 建的请求监听，以及 requestEvent 订阅的回执；“发的事件”包括响应器自动 emit 的 result。
- 标注的 inject 是 index.ts 导出的硬依赖，不等于本目录所有可选依赖；ctx.get/ctx.inject 和遗留直接调用见事件盘点。HTTP app.get/post 等注册属于服务接入，不伪装成事件。
- channels 是不挂服务的协议插件，不在 BUILT_IN 里；渠道调用它的 registerTextReply 会在渠道自己的 ctx 上挂 channel/reply 并发 channel/replied。
- 插件名 wechat 与 wechat-kefu 是同一模块的注册别名，不按两个业务插件计数。骨架 ready 只说明生命周期，不证明插件运行验收已通过。

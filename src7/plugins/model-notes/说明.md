#### 评分请求字段

| 字段 | 类型 | 必填 | 默认及规则 |
|---|---|---|---|
| `session` | string | 是 | 先要求原值非空string，再trim；trim后^[A-Za-z0-9_-]+$，不限定20位，也接受旧短ID；无/、点、空格 |
| `by` | string | 是 | 先要求原值非空string，再trim；trim后非空，不含·或剩余CR/LF；无固定enum，大小写敏感；用户/Claude/Codex/Grok/Antigravity只是合法示例标签，不是身份认证 |
| `score` | number | 是 | ；Number.isInteger且1..5，字符串4、浮点、NaN/Infinity不接受；JSON例用数值4 |
| `note` | string（也接受省略/null归默认） | 否 | 省略或 null 为空字符串；noteWritten=item.note??空串；先检原noteWritten无CR/LF，再trim入结果；可空、可含·，不能原始CR/LF；非null非string如number400。session/by的外围空白先trim，不能误写原始任意换行都必拒绝。 |

其他键（包括旧 `model`、`task` 和 `thinking`）被忽略，不能覆盖模型归属；没有 `session` 的旧请求仍会因缺字段返回 400。`src7/utils/Checks.ts:351`。

## 数据

不建数据库表。模型资料存储在 `Settings.dir` 下，文件名将模型 ID 中 `/` 替换为 `__`；目录只读取普通 `.md` 文件，不递归。介绍位于标题后、评价节之前。

### 评价文件

新行：`- <YYYY-MM-DD HH:mm TZ> · <by> · <score>/5 · 会话 <session>（<thinking>） · <note>`。空则省略整个全角括号；非空来自row.thinking trim；空则新行省略最后分隔与评语。

旧行：`- <at> · <by> · <score>/5 · 任务：<task> · <note>；能读能显示且参与统计，不自动重写为session行`。评价节精确trim == ## 评价，至下一原始行startsWith#停止；坏行跳过。新旧行均不验证时间/by是否真实，评分只认1..5。

同session/by精确字符串比较，API by/session已trim；跨文件先清其他模型同对，然后当前评价节删旧插新，介绍和其他节保留，换行沿原CRLF/LF；无联合事务/原子写/并发锁。by是调用者标签，不是经认证的真人/AI身份。

### 会话数与平均分

dedup nonempty(session,by) last wins → each nonempty session average(raters) → each legacy session-empty row independently → unweighted mean(all units) → Math.round(*10)/10

unique nonempty session count + count(valid legacy rows)。按文件顺序去重保留后位置，非按at时间戳排序；getPrompt取最后3条反向，getList不逆序。

例：概念例：会话A两人打5/3先得4，会话B一人2，另1旧任务行5，则N=3、average=3.7；只是算法说明，无真实评分操作。依据：`src7/plugins/model-notes/index.ts:187`、`src7/plugins/model-notes/index.ts:209`、`src7/plugins/model-notes/index.ts:219`、`src7/plugins/model-notes/index.ts:226`。

评分归属：来自sessions.open(session).row.model，不是body.model；thinking=String(row.thinking??空串).trim()；checkModelId先text+trim，用/分段，每段字母/数字开头，其后字母/数字/点/下划线/横杠，禁止__；不要求有/、存在provider或catalog；来自文件名getList不调用该验证。只证明当前会话记录选择值，不独立证明每条fallback回答实际生成模型/上游档位。 依据：`src7/plugins/model-notes/index.ts:448`、`src7/utils/Checks.ts:301`。

## 给外部 AI 的打分接口

只给你已核实完成表现的已有会话打分。会话号从主网页会话面板复制，或查询已有 `GET /api/sessions?bot=<机器人名>` 列表的 `id`；列表只列该机器人无 parent 会话，子会话可从相关会话记录/正在运行列表取得。不要新建会话代替原会话。

本机地址：`POST http://127.0.0.1:30086/api/model-notes/rate`。远端地址示例：`POST http://backend.example:30086/api/model-notes/rate`。30086为约定示例，实际端口及是否挂载以运行端为准。发送 `Content-Type: application/json`。

```json
{"session":"EXISTING_SESSION_ID","by":"Codex","score":4,"note":"已核实的完成情况与不足"}
```

把 `EXISTING_SESSION_ID` 替换为已有真实会话ID，分数与评语也按真实验收填写。session是非空字符串，只允许字母/数字/下划线/横杠，不限20位；score必须是数值整数1至5。by没有枚举，可写用户、Claude、Codex、Grok、Antigravity等非空标签；trim后不能含 `·` 或内部换行。note可省略或null（当空串），若为文字则不能含换行；可含 `·`，两端空白会去掉。

不要提交model或thinking来指定评分归属：服务端读取这场会话当前row.model/thinking。旧model/task及其他多余键会被忽略，不是全体多余键都报错。该归属不独立证明fallback实际生成模型或上游实际推理档。

同一by给同一session再次提交就是改分，旧分删除后新分排到评价末尾；by不同则可各有一条。若会话当前模型已改变，其他模型文件里同一by/session的旧项也会清理。每个真实session先算多人均分，再按会话等权平均；兼容的旧“任务：”行每条另算一个统计单位，因此sessionCount不保证全部是真实会话数。

本机与配置可信IP免令牌；其他远端在后端有有效令牌时带 `Authorization: Bearer <ACCESS_TOKEN>`（或query token）。没有启用任何有效令牌时当前服务放行；不要把此例写成所有远端一律必带。不能把by标签当认证身份。

成功200返回 `{ok:true,note:ModelNote}`；请求字段校验失败400返回 `{error}`；会话打开失败404返回 `{error}`；全局鉴权不通过401返回 `{error}`。文件读写、会话模型ID异常等未捕获错误交Fastify默认服务器错误处理（通常500，本插件无固定500 JSON合同），不能把这类错误伪写成400。接口本身未定义403/409/422或回执队列；本页也不保证跨文件写入事务或并发锁。

#### web_search

- 定义：`src7/plugins/web-search/index.ts:65`
- 返回 `Promise<string>`。
  1. 首行写本次用哪家及此前失败。
  2. 空一行后接结果。正文最多前 20000 字符，超出时提示省略及总字数。
- 按配置顺序尝试供应商。
  1. trim 后不足 20 字符视为失败。异常脱敏后继续。
  2. 停止时直接退出，不尝试下一家。
  3. 全部失败时抛汇总。
- 会话类型：front；work

### 外部数据

- `SearchProvider` 的内存字段有 kind、name、url、apiKey 和可选 model。
- Magpie 请求字段
  - `id` 取 `jmbots-时间`。
  - `model` 为模型，`input` 为用户 query。
  - `commands.search_query` 为 `[{q:query}]`。
  - `settings` 为 `{search_context_size:medium,allowed_callers:[direct],external_web_access:true}`。
  - `max_output_tokens` 为 2500。
- 响应只读 output。
- **依据**
  - `src7/plugins/web-search/index.ts:143`
- MCP 使用 JSON-RPC 2.0。
  1. initialize 用协议 `2025-03-26` 和 clientInfo `jmbots v1`，读取 `Mcp-Session-Id`。
  2. 从工具列表取 `name` 和 `inputSchema.required`。
  3. 从结果取 `content[].text` 和 `isError`。

  网页结果正文透传，本插件没有固定结果 schema。
- **依据**
  - `src7/plugins/web-search/index.ts:191`

## 设计要点

- 按配置顺序试供应商，空结果或失败才降到下一家；结果交回来源，不伪造统一可信的答案。
- 模型把网页当不可信数据，搜索插件不替网页指令授权工具；保留来源网址供核查。
- 每个请求有超时并继承会话取消，停止后不再试别的供应商。
- 密钥只放请求头，错误回显按实际 key 掩去；这不是全平台通用的 secrets 替身。

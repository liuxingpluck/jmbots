# http v1.3.2

提供 Fastify HTTP 服务：健康检查、访问令牌、外网反向代理会话 Cookie 登录鉴权（`WebAuth.ts`）、网页托管（`Static.ts`，插件页面与单页兜底，由 http 在 ready 监听前调用 `registerStatic`）、文件上传读取与目录接口（`Files.ts`，`FilesApi` 由 `registerStatic` 创建，不单独登记服务）；ready 后监听并维护 PID 文件。
关键边界：令牌管理只许本机；外网登录鉴权仅对带 `X-External-Proxy: 1` 且配置了 `web_auth` 的请求生效（家里 `127.0.0.1` 与内网虚拟机直连无此请求头，`required` 恒为 `false`）；业务路由归各插件；无令牌放行的分支见“设计要点”；文件接口只读 bots、skills、memory、knowledge 四个目录，拒 `config.yaml`、`secrets.yaml`、`.env`。
分工：`index.ts` 服务和令牌校验，`Tokens.ts` 令牌，`WebAuth.ts` 外网反向代理 Cookie 鉴权，`Routes.ts` 登记路由记录，`Static.ts` 网页，`Files.ts` 文件接口。

#### POST /api/service/stop

- 请求来源须满足以下条件。
  - 本机环回地址。
  - 请求无 `Origin`。
  - 带 `x-jmbots-window: 1`。
  - 来源或标记不满足返回 403，请求体不参与核对。
  
  [路由实现 · `Http.constructor` · index.ts:223](index.ts#L223)
- 进程须满足以下条件，否则返回 409。
  - 主站处于基地守护（`JMBOTS_SUPERVISED=1`）。
  - 尚未开始关停。
  - `x-jmbots-expected-pid` 与当前进程号一致。
  
  [进程核对 · `Http.constructor` · index.ts:223](index.ts#L223)
- 关停按以下顺序处理。
  1. 返回 202 和主站 PID，基地据此等待退出。
  2. 回执写出后，主站停止接收 HTTP 请求。
  3. 等待已挂载的 `programs` 关闭托管程序。
  4. 关闭数据库并以退出码 0 结束。
  - 202 表示已接受关停，实际退出由基地观察。
  
  [关停顺序 · `Http.shutdownForWindow` · index.ts:310](index.ts#L310)

#### GET /*

- 定义：`src7/plugins/http/Static.ts`
- 返回页面或资源的 Buffer。
  - 未知 API、带扩展名但不存在的文件、未打包的主页回 404。
  - assets 长缓存一年，标 `immutable`。其他资源用 `no-cache`。
- 处理顺序
  1. 拒绝未知 API。
  2. 探测任意 `<name>.html`，兜底不要求启用插件名单。缺尾 `/` 时回 301。
  3. 找文件及子路径的 assets，MIME 由 `mime.getMimeType` 得出。
  4. 带扩展名的文件找不到时回 404，其余走 SPA 兜底 `index.html`。
- 调用说明：浏览器访问页面及HTML打包资源引用；名称/文件动态生成，无固定静态请求调用方。

#### GET /api/files

- 定义：`src7/plugins/http/Files.ts`
- 返回二进制流。
  - 200 返回整份，206 返回片段。
  - 416 带 `Content-Range: bytes */size`。
  - 400 路径非法。
  - 403 越范围或名称被禁。
  - 404 无文件。
- 读取步骤
  1. 路径 resolve 一次，再 stat file。
  2. 设 `Accept-Ranges: bytes`、按后缀取 MIME，并设置 `Content-Length`。
  3. Range 结束过长时截到末尾，非法范围回 416。

## 设计要点

原有免令牌放行继续生效。身份核验标记仅保留在服务端当次请求，供程序界面代理使用。

- 本机访问有标记。
- 已通过令牌校验的远程请求有标记。
- 未配置令牌时，远程访问照常放行且无标记。
- 只靠 `server.trusted_ips` 放行的远程请求无标记。

- 单个 Fastify 按路径承载各业务插件，ready 后统一监听，所以插件可以先登记路由；业务路由属于各插件。
- HTTP 集中管理以下边界。
  - 访问令牌
  - 本地与可信 IP
  - 开放路由
  - 进程健康与插件 problems 分开，免得看门狗把插件失败当进程死亡。

当前边界：当前存在无令牌放行和可信 IP 等分支，不把它概括为所有远程请求都必需令牌。

# image-gen v1.0.4
生成图片保存到本轮工作区，沿用会话地址上的隔离目录。

机器人名单和目录等只读值由 utils/Bots.ts 读取。

生图工具依次执行。

1. 使用所配图片模型生成一张 PNG。
2. 保存到机器人工作区。
3. 返回 @路径。

#### image_generate

- 定义：`src7/plugins/image-gen/index.ts:68`
- 返回：Promise<string>：已生成：@<绝对.png路径>（大小），附reply里引用@路径的提示。
- 作用
  1. POST images/generations 取 data[0]。
  2. 优先用 b64_json，否则下载 url。
  - size 默认 1024x1024，schema 为 string，不限枚举。
  - background 默认 auto。
  - name 默认取 prompt 前 20 字，再调用 getSafeName。
- 会话类型：work

## 设计要点

- 生图工具只生成并保存单个产物，渠道按自己的附件规则发送，模型服务和渠道不耦合。
- 模型接口参数交提供方校验。超时和会话取消都覆盖两个请求。
  - 生成
  - 下载
- 当前能力范围
  - 保存到机器人 workspace。
  - 工具为 work 能力，外部身份可用性由权限层控制。
  - 当前生成单张图片。

#### GET（Fastify也自动HEAD） /<启用插件名>

- 定义：`src7/plugins/web/index.ts`
- 返回：301 Location:/<name>/
- 作用：具体插件页跳转
- 调用说明：浏览器访问页面及HTML打包资源引用；名称/文件动态生成，无固定静态请求调用方。

#### GET（Fastify也自动HEAD） /<启用插件名>/

- 定义：`src7/plugins/web/index.ts`
- 返回：text/html UTF8，no-cache；后来html丢失返回NOT_BUILT文字但不改默认状态
- 作用：具体插件页优先于通配
- 调用说明：浏览器访问页面及HTML打包资源引用；名称/文件动态生成，无固定静态请求调用方。

#### GET（Fastify也自动HEAD） /*

- 定义：`src7/plugins/web/index.ts`
- 返回页面或资源的 Buffer。
  - 未知 API、带扩展名但不存在的文件、未打包的主页回 404。
  - assets 长缓存一年，标 `immutable`。其他资源用 `no-cache`。
- 处理顺序
  1. 拒绝未知 API。
  2. 探测任意 `<name>.html`，兜底不要求启用插件名单。缺尾 `/` 时回 301。
  3. 找文件及子路径的 assets，MIME 由 `mime.getMimeType` 得出。
  4. 带扩展名的文件找不到时回 404，其余走 SPA 兜底 `index.html`。
- 调用说明：浏览器访问页面及HTML打包资源引用；名称/文件动态生成，无固定静态请求调用方。

##### PUT /api/uploads/:name

- 定义：`src7/plugins/web/Files.ts`
- 返回：{id:string(20位),name:string,size:number字节,kind:FileKind}
- 作用：上传作用域removeAllContentTypeParsers后*解析器直接给stream，pipeline写暂存文件，文件名清理见数据

##### GET /api/files

- 定义：`src7/plugins/web/Files.ts`
- 返回二进制流。
  - 200 返回整份，206 返回片段。
  - 416 带 `Content-Range: bytes */size`。
  - 400 路径非法。
  - 403 越范围或名称被禁。
  - 404 无文件。
- 读取步骤
  1. 路径 resolve 一次，再 stat file。
  2. 设 `Accept-Ranges: bytes`、按后缀取 MIME，并设置 `Content-Length`。
  3. Range 结束过长时截到末尾，非法范围回 416。

##### GET /files/*

- 定义：`src7/plugins/web/Files.ts`
- 返回：同/api/files
- 作用：便于其他程序按相对根路径拿文件，仍检查允许目录

##### GET /api/files/list

- 定义：`src7/plugins/web/Files.ts`
- 返回：{name,path,dir:boolean,size:number,mtime:number}[]；400/403/404错误{error}
- 作用：过滤禁止文件名，逐条stat（失败大小/mtime0），目录先、zh-CN名称排序

### 数据

#### 数据库表

- 无

#### 文件

- 路径：<root>/data/tmp/uploads/<id>_<name>
- **字段**
  - id：本地yyyyMMddHHmmssSSS+3位Math.random，20数字
  - name 清理顺序
    1. 扩展名不超过 10 字符才保留，且只留点、字母、数字、下划线和横线。
    2. 主文件名去控制字符和 Windows 非法字符，trim 后把空白转为 `_`，截到 60 字符，去掉尾部的点和 `_`。
    3. 结果为空时用“未命名”。
  - content：上传原始字节，缺body空文件；无JSON/表单字段解析
  - size：stat字节数
  - kind：mime.getFileKind(name)返回附件类别
- 来源：`src7/plugins/web/Files.ts`
- consumer：`src7/plugins/web-api/index.ts:344`
- 路径：<root>/{bots,skills,memory,knowledge}/...
- 范围只用于读取文件和列目录，不写这些目标。
  - 禁止 `config.yaml`、`secrets.yaml`、`.env` 和 `.env.*`，目录列表也不显示。
  - `/api/files` 的 path 用绝对路径，`/files/*` 相对 root。
- 来源：`src7/plugins/web/Files.ts`

### 配置

`plugins[web].config.files`

- 可省略或写 `{}`。原 `files-api` 没有子配置项，非法类型或非空对象在注册任何路由前拒绝。
- 保留原四个路径、上传目录、响应形状和目录范围。
- HTTP 继续执行原令牌策略。上传原始流解析器只在自己的 Fastify 子作用域生效。

Fastify路由随原HTTP生命周期使用，插件增删/更新按整体服务重启生效；不承诺热拔插路由，也不把原词法目录约束宣传为符号链接沙箱。

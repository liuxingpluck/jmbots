## 数据

### 数据库表

`assist_items` 存协助工具留下的东西：点的表情（react）、问用户的卡片（ask）、待办（todo）；一行是一项，挂在某条收件消息下。

| 列名 | 类型 | 能不能空 | 意思 | 谁写、什么时候写 |
|---|---|---|---|---|
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | 否 | 记录号 | `Assist.add` 插入时自增 |
| `bot` | TEXT NOT NULL | 否 | 机器人 | `add`，模型调协助工具时 |
| `kind` | TEXT NOT NULL | 否 | `react` / `ask` / `todo` | `add` |
| `session_id` | TEXT NOT NULL | 否 | 产生这一项的会话 | `add` |
| `message_id` | INTEGER | 能 | 这个机器人最新一条 `web_messages.id`（挂在哪条消息下） | `add` |
| `data` | TEXT NOT NULL | 否 | 按 kind 存的 JSON；ask 答了以后多一个 `answer` | `add` 写；`POST /api/assist/asks/:id` 回答卡片时 UPDATE |
| `created_at` | INTEGER NOT NULL | 否 | 创建毫秒时刻 | `add` |
| `updated_at` | INTEGER NOT NULL | 否 | 最后改动毫秒时刻 | `add` 写；回答卡片时更新 |

删：`deleteTodos` 删指定会话的 todo 行。

依据：建表 `src7/plugins/assist/index.ts:51-53`；写 `:169`（`add`）、`:145`（回答 ask）、`:193`（`deleteTodos`）。

data 的 JSON：react `{emoji}`；ask `{question, options[], answer?}`（answer 由回答接口加）；todo `{items: {text, status: todo|doing|done}[]}`。

读别人的表：`web_messages`，取这个机器人最大的 id 挂这一项（`src7/plugins/assist/index.ts:165`）。

# skills v1.0.1

为work会话现扫全局与机器人技能清单，并提供受目录约束的只读skill工具。

## 随源码带的技能

插件目录下的 `dsh-control/` 是一份技能的源码（不是插件，编译不进程序）：把活交给 Windows 上的 DSH。装法：把整个目录复制到 `<数据根>/bots/<机器人>/skills/dsh-control/`，再照 `settings.example.json` 写一份 `settings.json`（DSH 客户端路径、登记的工作区、默认等多久）。

- `SKILL.md`：work 会话用 skill 工具读，写清何时用、怎么跑、输出怎么看；读它不会跑任何东西。
- `scripts/dsh.mjs`：work 会话用 exec 显式跑；每一步调现有的 DSH 客户端 `ztools/dsh-control/Dsh_Control.mjs`，不自己连 DSH、不读令牌；只认 `settings.json` 登记的工作区（和当前目录精确相同）；记录写在工作区 `.dispatch/<任务号>/dsh.json`。
- 测试：`DshSkill.test.ts`（假客户端，不连真 DSH）。

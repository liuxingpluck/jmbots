# settings v1.0.6

以下操作统一判断回执缺失。在途状态可能已生效时提示先核对。

- 实时登记机器人
- 关闭 HTTP
- 请求基地重启

为设置页读改配置、新建机器人，并按守护/源码模式重启。

- `model-catalog/result`

- `bot/result`

#### GET /api/settings

- 定义：`src7/plugins/settings/index.ts:62`
- 返回
  - 成功回 `{config}`，只包含白名单配置，密钥字符串换成临时代号。
  - YAML 不合法回 409。其他错误回 400 `{error}`。
- 作用：设置管理入口。

#### PUT /api/settings

- 定义：`src7/plugins/settings/index.ts:62`
- 返回：{ok:true,changed:步骤数,note:修改段及重启提示}；非法400/YAML409{error}
- 写入步骤
  1. 按顺序改 YAML，保持注释、顺序和 BOM。
  2. 通过骨架 `checkConfig` 校验。
  3. 写 `.tmp` 后改名。

  `resources.raw` 不随写入改。

#### POST /api/bots

- 定义：`src7/plugins/settings/index.ts:71`
- 返回
  - 成功回 `{ok:true,bot:{name,language},feishu?}`。
  - 参数或重名错误回 400。
  - 实时登记失败回 503，并提示配置已保存，可在重启时生效。
- 配置写入 `bots` 和可选的 `channels.feishu`，再用登记回执里的记忆目录初始化索引。

#### POST /api/settings/apply

- 定义：`src7/plugins/settings/index.ts:77`
- 返回 {ok:true,startedAt:number,note:string}。重复重启回 409，探活事件失败回 503。守护模式直接本地退出。
- 作用：设置管理入口。

#### POST /api/service/restart

- 定义：`src7/plugins/settings/index.ts:72`
- 返回
  - 重启受理后回 `{ok:true,startedAt:number,note:string}`。
  - 基地明确拒绝或缺少接口回 409。
  - 无人接单回 503。
  - 基地响应超时或中断回 504，提示重启结果不确定并保留占用。
- 作用：设置管理入口。

## 设计要点

- 配置编辑用白名单和 YAML 文档保留结构，写整份校验后原子替换；运行时配置和磁盘上待应用的配置分开。
- 设置页的“已设置”代号只为避免界面回显，内存映射失效须刷新；它不是模型、工具、日志通用的密钥保险库。HTTP 的令牌处理和资源认证由各自模块承担。
- 基地是可选的重启协作者，缺服务或旧 404 可回本地路径；基地无响应明确回 503，不影响本地配置和新建机器人。
- 模型有效性可用时再问 modelCatalog，新机器人用现成的 Bots.add；飞书连接等启动配置仍需应用。

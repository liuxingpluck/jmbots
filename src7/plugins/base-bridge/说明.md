# base-bridge v1.1.0

提供 `ctx.base` 请求服务、8 条网页基地转发接口，以及可选的基地通知（`Notify.ts`，原 `notify`）与更新监听（`UpdateWatch.ts`，原 `update-watch`）。

## 依赖

| 服务 | 类型 | 用途 | 位置 |
|---|---|---|---|
| resources | 必需 | 入口读 `engine.index_url`、通知读取 `server.port`、更新状态文件目录 `data/`。 | `src7/plugins/base-bridge/index.ts`、`src7/plugins/base-bridge/Notify.ts`、`src7/plugins/base-bridge/UpdateWatch.ts` |
| http | 可选 | HTTP 就绪后循环登记 8 条基地转发路由；`ctx.base` 可独立挂载。 | `src7/plugins/base-bridge/index.ts` |
| tools | 可选（仅开启 `config.notify` 时 inject） | 登记模型工具 `notify_user`。 | `src7/plugins/base-bridge/index.ts`、`src7/plugins/base-bridge/Notify.ts` |
| bots | 可选（仅开启 `config.update_watch` 时 inject） | 获取第一个机器人与往前台会话发消息。 | `src7/plugins/base-bridge/index.ts`、`src7/plugins/base-bridge/UpdateWatch.ts` |
| approval | 可选（仅开启 `config.update_watch` 时 inject） | `ask` 新版本待确认、`list`/`decide` 过时项。 | `src7/plugins/base-bridge/index.ts`、`src7/plugins/base-bridge/UpdateWatch.ts` |
| sessions | 可选（仅开启 `config.update_watch` 时 inject） | 查找机器人最新 `front` 会话报告更新结果。 | `src7/plugins/base-bridge/index.ts`、`src7/plugins/base-bridge/UpdateWatch.ts` |

## 听的事件

| 事件 | 位置 | 收到后做什么 |
|---|---|---|
| `approval/asked` | `src7/plugins/base-bridge/Notify.ts` | 仅开启 `config.notify` 时监听：发出标题“有待确认”的通知。 |
| `progress/update` | `src7/plugins/base-bridge/Notify.ts` | 仅开启 `config.notify` 时监听：任务进入终态（`done`/`error`/`stopped`/`timeout`/`flagged`/`handed`）时按 `sessionId:id:stage` 去重发一次通知。 |
| `ready` | `src7/plugins/base-bridge/UpdateWatch.ts` | 仅开启 `config.update_watch` 时监听：在 `first_ms` 后调度第一次版本检查。 |
| `approval/decided` | `src7/plugins/base-bridge/UpdateWatch.ts` | 仅开启 `config.update_watch` 时监听：处理 `kind==='update'` 决议（拒绝则记入 `declined`，同意则调 `/update/apply` 并将状态写入 `swapping`）。 |

## 数据

### 数据库

- 无

### 文件（仅开启 `config.update_watch` 时读写）

- 路径：`<runtime>/data/update_watch.json`
- 字段：
  - `declined?: string`：用户明确拒绝的版本，不再重复登记；
  - `swapping?: { version: string; bot?: string }`：用户同意并成功触发 `/update/apply` 后暂存，下次检测到非 `applying` 时向前台汇报结果并移除。

### 共享字段

| 字段 | 类型 | 用途 | 源码 |
|---|---|---|---|
| `Pending.kind/title/payload/state/by/bot` | 见 `Approval` | `notify` 读 `approval/asked` 的标题；`update_watch` 读写 `kind==='update'` 条目 | `src7/plugins/base-bridge/Notify.ts`、`src7/plugins/base-bridge/UpdateWatch.ts` |
| `ProgressItem.stage/sessionId/id/result/action/text` | 见 `Progress` | `notify` 筛选终态事件并按 `sessionId:id:stage` 去重 | `src7/plugins/base-bridge/Notify.ts` |
| `SessionRow.bot/kind/id` | 见 `Sessions` | `update_watch` 寻找机器人最新 `front` 会话报告更新结果 | `src7/plugins/base-bridge/UpdateWatch.ts` |

## 配置

| 配置键 | 默认 | 用途 | 位置 |
|---|---|---|---|
| `engine.index_url` | `''`（允许不配独立运行） | 须为 `string`，去掉空白和末尾 `/` 后须是无 query/hash 的 `http://` 或 `https://` 地址 | `src7/plugins/base-bridge/index.ts` |
| `plugins[base-bridge].config.notify` | **`false`（默认关闭）** | 不写或 `false` 不注册 `notify_user` 与通知监听；写 `true` 或 `{ url?, enabled? }` 开启（`url` 覆盖 `/notify` 完整地址） | `src7/plugins/base-bridge/Notify.ts` |
| `plugins[base-bridge].config.update_watch` | **`false`（默认关闭）** | 不写或 `false` 不启动版本检查定时器；写 `true` 或 `{ first_ms?, every_ms?, enabled? }` 开启（默认 `first_ms=10000`、`every_ms=60000`） | `src7/plugins/base-bridge/UpdateWatch.ts` |
| `server.port` | 未单列 | 为 `number` 时用于拼接通知携带的可点击本地网页 URL `http://127.0.0.1:<port>/` | `src7/plugins/base-bridge/Notify.ts` |

### 怎么打开通知和更新监听（默认均关闭）

在 `config.yaml` 的 `plugins:` 下给 `base-bridge` 加上需要的子键即可：

```yaml
- name: base-bridge
  config:
    notify: true          # 或 { url: 'http://127.0.0.1:15762/notify' }
    update_watch: true    # 或 { first_ms: 10000, every_ms: 60000 }
```

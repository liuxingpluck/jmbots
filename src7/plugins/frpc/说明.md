# frpc v1.0.0

外网隧道（frpc）原生管理插件：提供状态巡检、无黑框进程启停/平滑重启、Windows 开机自启开关、`[[proxies]]` 隧道映射无损可视化编辑与实时脱敏日志读取接口，配合 `/frpc/` 前端控制台与 Windows 右下角系统托盘脚本协同工作。

## 依赖

- inject `http`（`http` 已依赖 `resources`）：在 `ctx.http.app` 上登记 `/api/frpc/*` 路由，并复用 `ctx.http.isVerified(request)` 核验所有写操作身份。

## 配置（`config.yaml` 的 `plugins.frpc`）

- `dir`（可选字符串）：frpc 客户端目录路径；缺省自动定位 `<aidata>/works/frp-clients/windows`（兼容运行版往上两级与源码开发版往上三级目录布局）。

## HTTP 接口

- `GET /api/frpc/status`
  - 读取 `frpc.toml`（解析 `serverAddr`、`serverPort`、`user`、`tlsEnabled`、`hasAuthToken` 与 `proxies`，绝不返回 `auth.token` 明文）、核验 `tray-status.json`（容错 UTF-8 BOM）与真实存活进程、检查 Windows Startup 目录 `LeonFRPS-Tray.vbs` 是否存在，并推导 `publicUrls`。
- `POST /api/frpc/control`（需 `isVerified`，请求体 `{ action: 'start' | 'stop' | 'restart' }`）
  - `start`：优先无窗拉起 `start-tray.vbs` 托盘常驻管理器，若隧道未起则直接无窗拉起 `frpc.exe -c frpc.toml`；
  - `stop`：仅精准停止当前目录下的 `frpc.exe`，保留托盘图标变红常驻；
  - `restart`：精准重启当前目录 `frpc.exe` 并等待短暂收敛后返回最新状态。
- `POST /api/frpc/autostart`（需 `isVerified`，请求体 `{ enabled: boolean }`）
  - 开启时在 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\LeonFRPS-Tray.vbs` 写入 2 行纯无窗 VBScript 转发调用 `start-tray.vbs`；关闭时幂等删除该文件。
- `PUT /api/frpc/proxies`（需 `isVerified`，请求体 `{ proxies: FrpcProxy[], restart?: boolean }`）
  - 严格校验隧道名称唯一性、协议、端口与域名；对 `localPort === 30086` 严禁填 `127.0.0.1` / `localhost`（防绕过外网 `AuthGate` 登录门禁）；
  - 写入前自动备份 `frpc.toml.bak`，无损替换 `[[proxies]]` 段落并 100% 原样保留头部注释、`auth.token`、`transport.tls.enable` 与 `log.*` 配置；`restart: true` 时自动平滑重启。
- `GET /api/frpc/logs?lines=120`
  - 截读 `frpc.log` 末尾最多 500 行，自动脱敏 `token`、`auth.token`、`credential`、`password` 与 `Bearer` 凭据。

# frpc v1.0.1

外网隧道：看 frpc 的状态，启停、开机自启，编辑隧道映射，读脱敏后的日志；网页控制台在 `/frpc/`。

- 只管本机这一个 frpc 客户端目录；隧道的服务端不归它管。
- 所有写操作都要 `ctx.http.isVerified`，`auth.token` 不出现在任何回执里；控制操作串行互斥，防并发拉起双进程。

## 依赖

- inject `http`（`http` 已依赖 `resources`）：在 `ctx.http.app` 上登记 `/api/frpc/*` 路由，并复用 `ctx.http.isVerified(request)` 核验所有写操作身份。

## 听的事件

无。

## 发的事件

无。

## 对外函数

### HTTP 接口

- `GET /api/frpc/status`
  - 读取 `frpc.toml`（解析 `serverAddr`、`serverPort`、`user`、`tlsEnabled`、`hasAuthToken` 与 `proxies`，不返回 `auth.token` 明文）、核验 `tray-status.json`（容错 UTF-8 BOM）与存活进程、检查 Windows Startup 目录 `LeonFRPS-Tray.vbs` 是否存在，并推导 `publicUrls`。
- `POST /api/frpc/control`（需 `isVerified`，请求体 `{ action: 'start' | 'stop' | 'restart' }`）
  - `start`：优先无窗拉起 `start-tray.vbs` 托盘常驻管理器，若隧道未起则直接无窗拉起 `frpc.exe -c frpc.toml`；
  - `stop`：只停当前目录下的 `frpc.exe`，保留托盘图标常驻；
  - `restart`：重启当前目录 `frpc.exe` 并等待短暂收敛后返回最新状态。
- `POST /api/frpc/autostart`（需 `isVerified`，请求体 `{ enabled: boolean }`）
  - 开启时在 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\LeonFRPS-Tray.vbs` 写入 2 行无窗 VBScript 转发调用 `start-tray.vbs`；关闭时幂等删除该文件。
- `PUT /api/frpc/proxies`（需 `isVerified`，请求体 `{ proxies: FrpcProxy[], restart?: boolean }`）
  - 校验隧道名称唯一性、协议、端口与域名；对 `localPort === 30086` 要求点分十进制非回环 IPv4（不许填 `127.0.0.1` / `localhost`，防绕过外网 `AuthGate` 登录门禁）；原 `frpc.toml` 含控制台暂不支持的高级代理字段时回 `409` 防丢失；
  - 写入前自动备份 `frpc.toml.bak`，替换 `[[proxies]]` 段落并保留头部注释、`auth.token`、`transport.tls.enable` 与 `log.*` 配置；`restart: true` 时自动重启。
- `GET /api/frpc/logs?lines=120`
  - 截读 `frpc.log` 末尾最多 500 行，自动脱敏 `token`、`auth.token`、`credential`、`password` 与 `Bearer` 凭据（兼容 JSON 引号键）。

## 内部函数

- `Toml.ts`：解析和回写 `frpc.toml`（`parseFrpcToml`、`rewriteProxiesSection`、`redactLogLine`），校验端口、域名与受保护端口非回环 IPv4 限制。
- `Process.ts`：通过 PowerShell 查询和停止当前目录下的 `frpc.exe`（`runFrpcScan`），无窗拉起托盘或 `frpc.exe`，并读写 Windows 开机自启脚本。
- `index.ts`：挂载 `/api/frpc/*` 路由、串行化控制操作并解析客户端目录。

## 数据

不建 SQLite 表，直接读写 frpc 客户端目录下的配置与运行文件：

- `frpc.toml` 与自动备份 `frpc.toml.bak`；
- `tray-status.json`（托盘状态）与 `frpc.log`（客户端日志）；
- `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\LeonFRPS-Tray.vbs`（开机自启转发脚本）。

## 配置

- `dir`（可选字符串）：frpc 客户端目录路径；缺省自动定位 `<aidata>/works/frp-clients/windows`（兼容运行版往上两级与源码开发版往上三级目录布局）。

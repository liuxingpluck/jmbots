# cli v1.1.4

把命令行文字通过统一事件 `channel/message` 发给指定或首个机器人（role owner、`routing.autoFinal`：前台一轮里 `channel_reply` 几次就逐条打几行，一次没调就打最后的话；`registerTextReply` 挂入 `getTargetAddress` 自认本机聊天；收尾 `channel/settled` 没回成时红字、退出码 1），在所有会话空闲后退出；`History.ts`（`CliHistory`）监听 `channel/history` 读 `channels/cli/*.jsonl` 回传 `channel/history-result`。

## 依赖

| 服务 | 类型 | 用途 | 位置 |
|---|---|---|---|
| resources | 必需 | 取 channels/cli 目录并按天落盘输入 JSONL | `src7/plugins/cli/index.ts` |
| bots | 必需 | 登记 cli 发送器、核对机器人名单 | `src7/plugins/cli/index.ts` |
| sessions | 必需 | 查 running 会话决定退出 | `src7/plugins/cli/index.ts` |

## 听的事件

| 事件 | 位置 | 收到后做什么 |
|---|---|---|
| ready | `src7/plugins/cli/index.ts` | void start(argv)，等所有插件挂好才发话 |
| session/change | `src7/plugins/cli/index.ts` | exitWhenIdle 检查命令已发且所有会话不 running 才退出 |
| channel/reply | `src7/plugins/cli/index.ts` | registerTextReply 响应模型的 channel_reply、零次兜底、审批直回，逐条打印并回发 channel/replied |
| channel/settled | `src7/plugins/cli/index.ts` | 命令行那一轮没回成：红字打原因，退出码记 1 |
| channel/history | `src7/plugins/cli/History.ts` | CliHistory 监听，本人可跨渠道查，外人仅当前命令行聊天；读 channels/cli/*.jsonl 并回发 channel/history-result |

## 发的事件

| 事件 | 位置 | 触发时机 | 携带内容 |
|---|---|---|---|
| channel/message | `src7/plugins/cli/index.ts` | Cli.submitLine 落盘后，直接 `ctx.serial` | 标准 ChannelMessage（runId:seq 稳定 sourceId、targetBots、[cli:本机]、role owner、`routing.autoFinal: true`）与 control；claims 为空且没被 approval 消费就报错 |
| channel/replied | `src7/plugins/cli/index.ts` | channel/reply 写完终端后 | requestId、replyRoundKey、v2 ReplyReceipt |
| channel/history-result | `src7/plugins/cli/History.ts` | 处理 channel/history（成功分页或权限/游标报错） | requestId、items、nextCursor、completeness、error? |
| trace | `src7/plugins/cli/index.ts` | Cli.submitLine 发事件前 | {机器人, 序号, 字数} |

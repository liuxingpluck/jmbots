# cli v1.1.8

命令行渠道把文字发给指定或首个机器人，在所有会话空闲后退出。

- `registerTextReply` 挂入 `getTargetAddress` 自认本机聊天。
- 一轮消息的处理顺序
  1. 经 channels 的 `emitInbound` 发 `channel/direct` 入站（命令行是私聊，called 恒为 true），role 为 owner，使用 `routing.autoFinal`。
  2. 每次 `channel_reply` 各打印一行，一次没调就打印最后的话。
  3. 收尾 `bot/settled` 没回成时显示红字、退出码 1。
- 所有发到命令行的话都经 `channel/reply` 到 `print`，向 bots 只登记渠道名 `ctx.bots.channel(name)`。
- 旧路自动回话（会话一轮结束、旧会话中途一句、前台送后台结果，没有来源快照）由 bots 的 `Bots.send` 发，带 `sessionId`，打 `[机器人 会话号] 话`，那场会话 failed 时红字、退出码记 1。

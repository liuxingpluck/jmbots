# context-fit v1.1.1

会话上下文总结、压缩与裁剪一体化插件（由原 `compress`、`context-fit`、`summary` 合一，对应方案名 `session-context`）：
1. `Summary`（`Summary.ts`）：干活的会话完成一轮（`state=done`）后，起 `summary` 小会话生成一两句总结写入 `row.summary`；
2. `Compress`（`Compress.ts`）：请求发送前（先听 `session/request`）检查上一步模型总 token，达到 `compress.at` 时起 `compress` 小会话把旧对话压成摘要写入 `compress_log`，并将本次 `request.messages` 替换为 `[摘要消息, ...后续原文]`；
3. `ContextFit`（`index.ts`）：紧随 `Compress` 之后监听 `session/request`，若压缩后的请求仍超出上下文窗口比例 `ratio`，先将较早工具结果换成“已省略”（保住最近 `keep` 条），仍超再按段丢失早期对话（保留最后用户话和最近 `keep` 段），只修改请求副本，原 `SessionRow.messages` 一字不动。

## 听的事件

| 事件 | 位置 | 收到后做什么 |
|---|---|---|
| session/change | `src7/plugins/context-fit/Summary.ts` | `summary` 开启时，仅在 `kind=work && state=done` 时异步开 `summary` 小会话写回 `row.summary`。 |
| session/request（先） | `src7/plugins/context-fit/Compress.ts` | `compress` 开启时，仅处理 `work` 会话：读取 `compress_log`，最后条 `assistant.usage.totalTokens >= compress.at` 时增量压缩，并在存在摘要时替换 `request.messages=[摘要消息,...row.messages.slice(upto)]`。 |
| session/request（后） | `src7/plugins/context-fit/index.ts:193` | 紧接 `Compress`，先用事件查模型窗口，再扣除系统提示和工具定义的用量。超预算时用 `fit` 替换 `request.messages`。 |

## 数据

### 数据库表（`ctx.resources.db`）

`compress_log` 存后台会话压到哪、摘要是什么；一行是一场压缩过的会话（只压 `work` 会话）。

| 列名 | 类型 | 能不能空 | 意思 | 谁写、什么时候写 |
|---|---|---|---|---|
| `session` | TEXT PRIMARY KEY | 否（主键） | 会话号 | `Compress.compress`：对话太长、跑完一场 `compress` 小会话写出摘要后写（INSERT OR REPLACE，再压就覆盖） |
| `upto` | INTEGER NOT NULL | 否 | 压到第几条消息（不含），之前的都用摘要代替 | 同上 |
| `summary` | TEXT NOT NULL | 否 | 摘要全文，以后每次 `session/request` 套在尾部消息前面 | 同上 |

依据：建表 `src7/plugins/context-fit/Compress.ts:65-69`；只压 work `:83`；写 `:147`（`compress`）。

## 配置

| 配置键 | 默认 | 用途 | 位置 |
|---|---|---|---|
| `plugins[context-fit].config.keep` | `6` | 非负整数；`fit` 最近保留的工具结果数与对话段数 | `src7/plugins/context-fit/index.ts` |
| `plugins[context-fit].config.ratio` | `0.9` | `0 < ratio <= 1`，上下文窗口使用比例 | `src7/plugins/context-fit/index.ts` |
| `plugins[context-fit].config.compress` | `{ at: 200000, keep: 6 }` | `false` 关闭压缩；对象则校验 `at`（触发压缩 token 阈值）、`keep`（压缩至少保留消息数）均为正整数 | `src7/plugins/context-fit/Compress.ts` |
| `plugins[context-fit].config.summary` | `true` | `false` 关闭总结；`true` 或对象开启 | `src7/plugins/context-fit/Summary.ts` |
| `providers.<供应商>.models.<模型>.context_window` | `128000` | 模型目录事件未返回窗口时通过 `resources.getModel` 读取的上限 | `src7/plugins/context-fit/index.ts` |

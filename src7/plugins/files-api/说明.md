# files-api v1.0.0

提供流式文件上传、受目录范围约束的文件读取和目录列表，并支持媒体Range读取。

#### PUT /api/uploads/:name

- 定义：`src7/plugins/files-api/index.ts:71`
- 返回：{id:string(20位),name:string,size:number字节,kind:FileKind}
- 作用：上传作用域removeAllContentTypeParsers后*解析器直接给stream，pipeline写暂存文件，文件名清理见数据

#### GET /api/files

- 定义：`src7/plugins/files-api/index.ts:77`
- 返回：二进制流，整份200或片段206；416 Content-Range:bytes */size；400路径非法、403越范围或禁止名、404无文件
- 作用：路径resolve一次，再stat file；Accept-Ranges:bytes，MIME按后缀，Content-Length；Range结束过长截末尾，非法范围416

#### GET /files/*

- 定义：`src7/plugins/files-api/index.ts:82`
- 返回：同/api/files
- 作用：便于其他程序按相对根路径拿文件，仍检查允许目录

#### GET /api/files/list

- 定义：`src7/plugins/files-api/index.ts:87`
- 返回：{name,path,dir:boolean,size:number,mtime:number}[]；400/403/404错误{error}
- 作用：过滤禁止文件名，逐条stat（失败大小/mtime0），目录先、zh-CN名称排序

### 文件

- 路径：<root>/data/tmp/uploads/<id>_<name>
- **字段**
  - id：本地yyyyMMddHHmmssSSS+3位Math.random，20数字
  - name：extension<=10字符才保留且只留点/字母数字下划线横线；stem去控制字符和Windows非法符，trim、空白转_、截60字符、去尾点/_；空用未命名
  - content：上传原始字节，缺body空文件；无JSON/表单字段解析
  - size：stat字节数
  - kind：mime.getKind(name)返回附件类别
- 来源：`src7/plugins/files-api/index.ts:21`
- consumer：`src7/plugins/web-api/index.ts:344`
- 路径：<root>/{bots,skills,memory,knowledge}/...
- 含义：仅读取文件/列目录范围；禁文件名config.yaml/secrets.yaml/.env和.env.*，目录列表也不列；/api/files path绝对，/files/*相对root；不写这些目标
- 来源：`src7/plugins/files-api/index.ts:33`

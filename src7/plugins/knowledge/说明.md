# knowledge v1.0.0

积木知识库（knowledge）后端插件：围绕「文档原子、多对多标签、虚拟目录树」三大核心构建单写源 SQLite 存储，支持与工作决策台（`/work-decision/`）专题节点 `topicId` 直接挂载关联，自动导出磁盘文件镜像，并通过 `requestEvent` 温和桥接 `memory` 混合检索。

## 依赖

- inject `resources`：共用应用主 SQLite 连接 `ctx.resources.db` 与运行时目录 `ctx.resources.root`。
- inject `http`：在 `ctx.http.app` 登记 `/api/knowledge/*` REST 接口，并用 `ctx.http.isVerified(request)` 拦截未核验写请求。
- inject `tools`：向 `front`（前台对话）与 `work`（后台干活）会话登记只读检索工具 `kb_search`。
- 可选 `db`（`ctx.get('db')`）：存在时将建表脚本纳入 `db_migrations` 账本。

## 核心表结构与磁盘镜像

1. `kb_dirs`：虚拟目录树（`id`, `parent_id`, `name`, `sort_order`, `created_at`, `updated_at`）。支持层级移动环路拦截；删除目录时子目录自动上提至原父级、原目录内文档解绑为未归类（`dir_id = NULL`），绝不误删原文档。
2. `kb_docs`：知识文档（`id`, `dir_id`, `topic_id`, `title`, `summary`, `content`, `source_path`, `source_type` [`note`/`file`/`url`/`transcript`], `created_at`, `updated_at`）。未显式填写 `summary` 时自动从 Markdown 正文提取导读摘要。
3. `kb_tags` + `kb_doc_tags`：大小写不敏感标签表与多对多映射，文档更新或删除时自动清理无引用孤立标签。
4. 磁盘镜像：每次文档变更同步原子导出至 `<runtimeRoot>/knowledge/YYYYMMDD/<id>_<标题>/{content.md, meta.json}`（支持 `plugins.knowledge.mirror_dir` 自定义路径）。

## HTTP 接口（写接口均需 `isVerified`，未核验回 `403`）

- `GET /api/knowledge/tree` → `{ ok: true, dirs, flatDirs, tags, topics, totalDocs, unassignedDocs }`
- `GET /api/knowledge/docs`（支持 `dirId`、`topicId`、`tag`、`q`、`limit`、`offset`、`includeContent`）→ `{ ok: true, items, total, limit, offset }`
- `GET /api/knowledge/docs/:id` → `{ ok: true, doc }`
- `POST /api/knowledge/docs` / `PUT /api/knowledge/docs/:id`（支持可选 `baseUpdatedAt` 乐观锁，与当前 `updated_at` 不一致时返回 `409` 并带回最新 `doc`） / `DELETE /api/knowledge/docs/:id`
- `POST /api/knowledge/dirs` / `PUT /api/knowledge/dirs/:id` / `DELETE /api/knowledge/dirs/:id`
- `GET /api/knowledge/search?q=...`：本地标题/标签/摘要/正文多字段加权检索 + 通过 `memory/request`（`action: 'search'`）温和融合记忆片段；未挂载 `memory` 或远端离线时平滑退化（`memoryAvailable: false, memoryHits: []`），零报错。

## 模型工具

- `kb_search`（只读，`sessionKinds: ['front', 'work']`）：不传筛选词时返回目录/标签/专题总览；传 `query`、`topicId`、`tag` 或 `dirId` 返回高信噪比摘要索引；传 `docId` 按需读取单篇完整正文。

# decision-map v1.1.0

中控把要用户定的事发到 `/decision-map/`。画布沿中心目标向四周展开，金色标主线，红星标待定。用户点一个选项后显示「已定 ✓」，中控收到并确认后变绿。

全图把同一父节点下已完成的子树收进 `+N` 小圆，点一下展开，再点收起。「聚焦主线」保留主线、待定及其祖先，「只看待定」保留待定及其祖先。手机首屏聚焦主线，沿长边布置，详情和选项从底部打开。

## 依赖与配置

`resources` 提供运行时目录，`http` 提供 API，`web` 托管 `web/decision-map.html` 构建后的页面。

在 `plugins` 中加入 `name: decision-map`。可填 `config.relay_helper`，值是 relay 已配置的中控助手名。配置为 `Claude` 时，现有 `ztools/remote-claude/Wait_Relay.mjs` 会从待收列表拿到新选择。收件以节点号去重，中控确认后从待收列表移除。relay 暂不可用时，中控可按版本号读取变化接口。

使用飞书提醒时，把手机可访问的决策图完整地址写入 `decision-map` 的 `config.public_url`。模板里的局域网地址可按实际网络调整。提醒链接使用同一运行时 `config.yaml` 中的 `server.token`。

## 接口

| 接口 | 参数和效果 |
|---|---|
| `GET /api/decision-map/graph` | 返回 `{ revision, nodes }`，供网页和中控读取。 |
| `PUT /api/decision-map/nodes` | 提交节点数组或 `{ nodes }`。已有节点保留未提供字段，整批校验通过才生效。 |
| `POST /api/decision-map/choose` | `{ node, option }`。先保存用户选择，再返回节点和中控收件号或变化接口。同一选择可重试。 |
| `GET /api/decision-map/changes?since=0` | 返回 `{ last, changes }`，按 `seq` 递增。用户选择的 `action` 为 `choose`。 |
| `POST /api/decision-map/ack` | `{ node, note? }`。记中控确认时间，同时归档对应的 relay 收件。 |

同一图有一个 `goal` 根节点，`parent` 表示分叉；`main: true` 从根向外连成一条路径。`pending` 且 `status: open` 的节点有可选的 `options`，每项含 `id`、`text`，可带 `recommended` 与 `cost`。

导入历史决定时，`decidedBy` 可填 `user` 或 `central`，`createdAt` 和 `decidedAt` 使用毫秒时间戳，`sources` 保存出处文档路径。详情栏显示这些记录，并标出当时选中的选项。

## 数据

`data/decision-map/graph.json` 存当前图及最近一次提交。`history.jsonl` 逐条追加其序号、时间、操作者、操作和相关节点，选项确定及收到确认时附选项或说明。快照先原子写入，中断后可用最近提交补齐最后一条历史。

## 听和发的事件

| 事件 | 用途 |
|---|---|
| 发 `decision-map/chosen` | 首次保存用户选择后通知订阅者，含节点号、选项号和标题。 |
| 发 `decision-map/relay` | 按配置请求投递或归档中控收件。入口在 relay，不推进机器人会话。 |
| 听 `decision-map/relay-result` | 按请求号接收 relay 回执。最长等待 3 秒，缺席时保留变化接口。 |

## 中控命令

```text
node ztools/central/Decision_Map.mjs add <节点文件.json>
node ztools/central/Decision_Map.mjs list
node ztools/central/Decision_Map.mjs done <节点号>
node ztools/central/Decision_Map.mjs notify --data <运行时目录>
```

脚本默认访问本机 jmbots，`JMBOTS_URL` 可指定别的实例。远程接口可使用 `JMBOTS_TOKEN`。

`notify` 也可通过 `JMBOTS_DATA` 选择运行时目录，查询端口取该配置的 `server.port`。命令把「决策图上有 N 件等你定」和链接写入 `integrations/feishu/outbox/` 的同一份 Markdown，终端只打印件数和文件路径。

## 实现位置

`Store.ts` 校验树、合并节点并持久化。`Routes.ts` 注册接口和通知。网页 `Layout.ts` 用 d3-hierarchy 计算角度与层深，主线分支获得双倍角度权重。React Flow 显示布局，选择栏提交后跟随新快照显示中控确认。

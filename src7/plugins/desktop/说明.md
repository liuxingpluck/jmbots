#### GET /api/desktop/status

- 定义：`src7/plugins/desktop/index.ts:120`
- 返回：{available:boolean,reason?:string}；只判断 Windows 和 exe 是否存在。
- 作用：检查能力是否可用，不起进程。

#### POST /api/desktop/action

参数和约束：

| 字段 | 类型、必填、默认及边界 |
|---|---|
| `body.op` | 必填 string；pick\|inspect\|capture\|scroll |
| `body.target` | 非pick必需对象；handle/rootHandle:1-16位十六进制可带0x；pid/threadId:正安全整数；className:非空字符串；processStartedAt:纯数字字符串；其他字段保留透传 |
| `body.direction` | scroll必需up\|down |
| `body.steps` | scroll默认1，整数1..10 |
| `body.x` | scroll默认0.5，有限数0..1 |
| `body.y` | scroll默认0.5，有限数0..1 |

请求体上限：16384 字节。

- 定义：`src7/plugins/desktop/index.ts:121`、`src7/plugins/desktop/index.ts:82`、`src7/plugins/desktop/index.ts:130`
- 返回
  - 200：原样返回能力进程的对象，要求非数组且 ok===true，无本插件固定完整 schema。
  - 400：参数错。
  - 503：不支持或未装。
  - 409：已有 pick，此时拒绝所有 action。
  - 502：运行、解析或取消错误，错误体 {error:string}。
- 执行顺序
  1. 隐藏启动 aobw-capability.exe。
  2. 把动作 JSON 行送入 stdin。
  - pick 超时 35 秒，其余 8 秒，输出上限 32MB。
  - 网页连接关闭时取消本次进程。

## 设计要点

- 窗口能力留在独立 exe。
  - HTTP 只允许固定操作。
  - HTTP 校验操作目标。
- 每个请求用独立的隐藏子进程。
  - 取消和超时只结束本次进程。
  - pick 活动期间暂拒其他操作，免得抢鼠标。
- 其他范围
  - 无模型工具。
  - 依赖由用户管理。
  - 截图只回传。

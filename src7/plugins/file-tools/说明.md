# file-tools v1.1.1

工作区写文件前使用 `utils/Files.ts` 的 `ensureDir` 创建父目录。

统一提供工作区基础文件、搜索和编辑工具。原 `base-tools` 插件已并入 `BaseTools.ts`。

- `time`
- `read`
- `list_dir`
- `write`
- `edit`
- `find`

用户 `@图片` 接入看图模型请求。

## 配置

无本插件独立配置段（按顶层 `providers.<供应商>.models.<模型ID>.vision` 决定模型是否收图片）；原 `base-tools` 已并入本插件，不再单独配置 `base-tools`。

## 设计要点

- edit 的写入约束
  - 对同一份原文校验后一次写回。
  - 唯一、不重叠的规则减少误改。
  - 模糊匹配只限已有的规范化规则。
- find 使用运行时自带能力，机器无需装 rg。
  - 限制文件体积、二进制和输出量。
  - 路径受当前身份的工作区边界约束。

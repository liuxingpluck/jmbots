# screen v0.1.0

基地在用户开启录屏讲解后，向后端提交一次已通过隐私检查的点击。插件以已配置的可读图模型生成一两句中文说明，通过当前请求返回。

## 依赖

- `resources` 读取顶层 `screen` 配置并提供单次模型调用。
- `http` 提供 Fastify 和统一鉴权。`voice` 为可选事件接收方。
- `src7/utils/RequestEvent.ts` 配对内部查询、控制、呈现确认及语音回执。

## HTTP

| 路由 | 输入 | 返回与副作用 |
|---|---|---|
| GET /api/screen/status | 可选 `clientId` | 协议号、可用性、固定原因、该客户端是否激活及生效配置。省略 ID 时只查可用性。 |
| POST /api/screen/state | 16 KiB 以内的 v1 客户端、会话、epoch、active 和动作 | `{ok, sessionId, epoch, active, leaseMs: 10000}`。允许主动开启、心跳、隐私暂停、停止和恢复。新会话须主动开启且 epoch 更高。 |
| POST /api/screen/click | 512 KiB 以内的 v1 点击；图像为最多 256 KiB 的预点击 JPEG，可用合规理由省略 | 讲解、身份、耗时、建议展示时长和语音资格。只处理活跃且匹配的会话，重复点击可复用 10 秒内的成功回执。 |

点击失败回固定中文提示及 `errorCode`。请求无效或版本不支持回 400，功能关闭回 403，会话失效、乱序、冲突或取消回 409，超限回 413，隐私阻断、缺少证据或模型输出无效回 422，模型失败回 502，模型超时回 504。身份已经有效时，失败体带原点击身份。HTTP 鉴权沿用 `http` 的响应。

## 事件

| 监听 | 回执 | 用途 |
|---|---|---|
| screen/status | screen/status-result | 读取可用性和租约。 |
| screen/control | screen/control-result | 用同一状态机处理已验证的内部控制。 |
| screen/presented | screen/presented-result | 以点击身份确认最新讲解已经展示。回执只含确认与语音状态。 |

| 发出的事件 | 内容 |
|---|---|
| screen/before-model、screen/after-model | 请求号、客户端、会话、epoch、点击号、模型、是否有图以及可写的 stop。 |
| screen/model-usage | 请求号、模型、实际 token 计数、耗时、是否成功及固定错误码。目前未纳入统一用量统计。 |
| voice/request | 配置允许且监听存在时，呈现确认后发 `speak`，中止旧会话时发 `stop`。使用 `sessionId_epoch` 作为组名。播报确认表示语音接口已接收。 |

## 函数

- `apply(ctx)` 校验配置、注册 HTTP 与内部事件。卸载时取消模型和语音并清理内存。
- `Screen.getStatus(clientId?)` 返回可用性与指定租约状态，清除已过期的状态和回执。
- `Screen.setState(input)` 处理已验证的控制输入，返回租约或固定错误。暂停、停止和换代取消旧请求。
- `Screen.explain(input, signal)` 生成或读取一条讲解。全局最多两条模型调用同时进行，更新的点击立即中止旧请求。
- `Screen.presented(input)` 确认最新的有效回执，一条回执最多请求一次语音。
- `Screen.dispose()` 取消所有请求和语音，清除租约、回执和清理定时器。
- `Protocol.ts` 校验配置、对象和字段，核对黑名单、图片字节数、JPEG 声明尺寸、裁图范围。校验后只下传模型需要的文字与图像、点击身份和窗口键。
- `Screen.getModelAnswer` 使用中文系统提示和空工具列表调用模型一次，校验回覆的 JSON、字数和句数，公开安全关口与计量。

## 内存

客户端记录会话、epoch、租约、最新序号、窗口身份和取消信号。租约 10 秒，失联后最多保留 30 秒的安全身份信息供拒绝迟到请求。成功回执全局最多 64 条，10 秒到期。换窗口、暂停、停止和换代清除旧回执。图片和控件数据只用于当前请求。插件无新增数据表和文件，也不把私有调度状态挂成 Cordis 服务。

## 配置

`config.example.yaml` 的顶层 `screen` 段列有默认值。默认 `enabled: false`、`speak: false`、模型为空。开启前须显式配置支持图像输入的 `供应商名/模型ID`。默认思考档为 `off`，模型请求最多 8 秒、不重试，输出预算 160 token。进程名和标题黑名单可追加，密码及锁屏保护在 v1 始终开启。基地只有完成本地隐私检查后才能提交点击。
